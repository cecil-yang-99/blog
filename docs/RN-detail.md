## React Native 与 ReactJs 有什么不同

React Native 是一个 javascript 框架， 由 Facebook 开发.
它调用 Objective-C 和 java 中的本地渲染 API

- 语法：React Native 和 ReactJs 都使用 JSX, 当 ReactJS 使用 HTML,而 React Native 不使用
- 导航。React Native 使用自己的内置导航库， 而 Reactjs 使用 react-router
- 动画。ReactJS 使用 CSS 动画。 ReactNative 使用其动画 Api.
- DOM。Reactjs 使用部分刷新的虚拟 DOM. ReactNative 在渲染 UI 组件时需要使用其本地的 api.
